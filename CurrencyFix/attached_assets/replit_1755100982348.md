# RIPT - Rupee Intelligence Platform Trade

## Overview

RIPT (Rupee Intelligence Platform Trade) is a comprehensive Special Rupee Vostro Account (SRVA) management system built with Streamlit. The platform facilitates international trade settlements in Indian Rupees (INR) for authorized countries including Russia, Germany, UK, Singapore, and other nations with established SRVA arrangements. The system provides end-to-end transaction processing, compliance monitoring, fraud detection, and regulatory reporting capabilities for banks and financial institutions managing cross-border INR settlements.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture
- **Framework**: Streamlit web application with multi-tab navigation structure
- **Layout Design**: Wide layout with expandable sidebar for optimal dashboard experience
- **Visualization Engine**: Plotly Express and Plotly Graph Objects for interactive charts and analytics
- **State Management**: Streamlit session state maintains database connections and API instances across user interactions
- **Mobile Integration**: QR code generation and scanning capabilities for mobile payment processing
- **User Interface**: Tab-based modular interfaces separating different functional areas (SRVA management, transaction processing, compliance tracking, etc.)

### Backend Architecture
- **Modular Design**: Ten specialized modules handling distinct business functions:
  - **SRVAManager**: Account creation, management, and bulk operations
  - **TransactionProcessor**: Trade transaction handling and lifecycle management
  - **SettlementCalculator**: INR settlement computations with real-time exchange rates
  - **ComplianceTracker**: RBI/FEMA compliance monitoring and regulatory reporting
  - **ReportingDashboard**: Analytics, metrics, and business intelligence
  - **DocumentGenerator**: Trade document creation and compliance report generation
  - **DataGenerator**: Random transaction and account generation for testing and demonstration
  - **QRCodeManager**: Mobile payment QR code generation and scanning functionality
  - **EncryptionManager**: AES and RSA encryption for secure transaction data handling
  - **AIFraudDetector**: Machine learning-based fraud and spam detection using scikit-learn
- **Business Logic Layer**: Separated into specialized classes for maintainability and scalability
- **Security Architecture**: Multi-layer encryption with AES for symmetric encryption and RSA for asymmetric operations
- **AI/ML Integration**: Fraud detection using Isolation Forest for anomaly detection and Random Forest for supervised classification

### Data Storage
- **Primary Database**: SQLite with normalized schema design for local data persistence
- **Schema Structure**: Optimized tables for SRVA accounts, transactions, exchange rates, compliance records, audit logs, and fraud detection data
- **Connection Management**: Context manager pattern ensures proper database connection handling and transaction integrity
- **Reference Data**: JSON files containing structured data for countries (20+ nations) and authorized banks with their SRVA capabilities
- **Caching Strategy**: In-memory caching for exchange rates and frequently accessed reference data

### Authentication & Authorization
- **Current Implementation**: No authentication system (designed for internal banking environment)
- **Security Model**: Application assumes trusted network environment with network-level security controls
- **Access Control**: All functionality available to authenticated users (suitable for internal banking operations)
- **Future Considerations**: Framework supports adding role-based access control for different user types (traders, compliance officers, administrators)

## External Dependencies

### APIs and External Services
- **Exchange Rate Providers**: Multi-provider support including Fixer.io, ExchangeRate-API, and CurrencyAPI with automatic fallback mechanisms
- **Real-time Data**: Live exchange rate feeds for 24+ currencies including major trading partners
- **API Management**: Rate limiting, caching, and error handling for external service reliability

### Third-party Libraries
- **Web Framework**: Streamlit for rapid web application development
- **Data Processing**: Pandas for data manipulation and analysis, NumPy for numerical operations
- **Visualization**: Plotly ecosystem for interactive charts and dashboards
- **Machine Learning**: Scikit-learn for fraud detection algorithms, Joblib for model persistence
- **Security**: Cryptography library for AES/RSA encryption implementation
- **QR Code Processing**: qrcode library for generation, OpenCV for image processing and scanning
- **Database**: SQLite3 for local data storage with potential for PostgreSQL migration

### Banking and Financial Standards
- **Regulatory Compliance**: RBI (Reserve Bank of India) and FEMA (Foreign Exchange Management Act) guidelines
- **International Standards**: SWIFT messaging standards for international payments
- **Banking Protocols**: Support for IFSC codes, SWIFT codes, and international banking identifiers
- **Currency Standards**: ISO 4217 currency codes and international exchange rate standards

### Infrastructure Requirements
- **Runtime Environment**: Python 3.7+ with support for all scientific computing libraries
- **Cloud Deployment**: Designed for Replit deployment with potential for scaling to cloud platforms
- **File Storage**: Local file system for documents and reports with support for cloud storage integration
- **Network Requirements**: Internet connectivity for real-time exchange rate feeds and external API integration
